Serve playback copies from Pages, not from Release assets

The gallery pointed <video src> at the GitHub Release asset. Release assets
are served as:

  Content-Type: application/octet-stream
  Content-Disposition: attachment; filename=...
  X-Content-Type-Options: nosniff

No browser will play that inline. nosniff blocks MIME sniffing and
octet-stream is not a playable video type, so every card opened an empty
player or triggered a download.

This was verified earlier with a range request that returned HTTP 206 and
read as a pass. 206 only proves the asset supports range requests; it says
nothing about whether the MIME type is playable. The check was measuring the
wrong thing.

Playback now reads site/videos/*.mp4, which Pages serves as video/mp4. The
download link still points at the Release, where attachment disposition is
the behaviour we actually want. 35.7 MB total against a 1 GB Pages limit.
